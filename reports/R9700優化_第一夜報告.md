## 星期一（11/23）預案：BIOS 1AAA ＋ DDR5 EXPO ＋ HW_QUEUES

**發現**：DDR5 條海盜船 CMK96GX5M2E6000Z36（rated 6000）由始至终行 3600 預設（EXPO 未開）。實測基線（WSL numpy triad 16線程）＝ **32.7 GB/s**；開 EXPO 目標 50-60 GB/s。125B expert miss 路徑、prefill staging、ComfyUI、WSL 全部食呢條帶。

**已預備**：
- BIOS 檔：`E:\backup\bios\7E49v1AAA.zip`（16.4MB，sha256 `e0c40a18...ea74`，解壓出 `E7E49AMSI.1AAA` 33.5MB，俾 M-FLASH 用）
- 板型確認：MSI **MPG** X870E CARBON WIFI（現 1.A80 → 目標 7E49v1AAA，AGESA PI 1.3.0.1f Patch A）

**流程**：
1. 插 FAT32 USB → 我解壓 `E7E49AMSI.1AAA` 去 USB root
2. 重啟入 M-FLASH 刷 1AAA（刷完自動入 BIOS setup）
3. 即刻開 A-XMP/EXPO Profile1 DDR5-6000（4×48GB 若不穩/過唔到 training → 手動 5600 或 5200；失敗 X870E 會自動 fallback，最差 clear CMOS）
4. 開機返入面我覆核：mem_bw.py（對比 32.7）、`strata_microbench`（decode 對比 88.5 基線）、1-2 日睇 WHEA/MCE events
5. 同場：`strata-125b-uc.json` env `GPU_MAX_HW_QUEUES 1→2` engine 重啟 A/B（斷線 ~4 分鐘）
6. 鐵規：改 config 前 copy 後備（Strata json＋launcher）

**風險**：EXPO 4 支 48GB 雙 rank 未必食到 6000 → fallback 5600/5200 都有 +33~55%；刷 BIOS 本身 10 分鐘，冇 dual-BIOS 但 MSI 有 flashback（背面 USB）。
